# hierarchical-depth-query-benchmark

Dataset and code for the study:
"Impact of Hierarchical Depth on Recursive Query Performance 
in Relational and Graph Databases Using Organizational Data"

## Dataset
Synthetic organizational hierarchy with branching factor 3.
Depth levels: 3, 5, 7, 10.

## Structure
- data/relational/ — CSV files for PostgreSQL import
- data/graph/      — CSV files for Neo4j import
- code/            — Dataset generation notebook
